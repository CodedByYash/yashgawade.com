## What REA is

<RepoCard
  repo="morluto/rea"
  description="REA (Reverse Engineer Anything): one MCP server for reverse engineering across binaries, apps and runtime behavior."
/>

REA is an MCP server. An agent connects to it, inspects a target, traces the relevant code, and reports findings with the evidence behind them and the limits of what it could tell. That makes it a good real-world example of the idea from the [MCP post](/blogs/mcp-model-context-protocol). [Say why you picked it.]

## Setting it up

The README gives a one-command setup for supported agents (Claude Code, Codex, Cursor, Gemini CLI and others), plus a standalone CLI:

<Terminal title="Setup">
{`
$ npx rea-agents setup
$ npm install --global rea-agents
$ rea --help
`}
</Terminal>

<Callout type="note" title="Check the official source">
  The README warns that similarly named repositories are not necessarily official. Download from the GitHub repo, rea.tools or the `rea-agents` package.
</Callout>
