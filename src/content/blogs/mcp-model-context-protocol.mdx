## What MCP is

The Model Context Protocol is an open protocol that lets an AI application talk to tools and data sources in one standard way, instead of a custom integration for every pair. [Add your own one-paragraph take.]

<Flow
  steps={["Host app", "MCP client", "MCP server", "Tool or data"]}

## The three things a server can offer

- **Tools**: actions the model can call.
- **Resources**: data the model can read.
- **Prompts**: reusable prompt templates.
